# ALTA Best Practices — Pillar 3 IT controls

## When to use
Title agencies, settlement companies and escrow agents preparing for an ALTA Best Practices self-certification or third-party assessment, or responding to an underwriter's security questionnaire. Pillar 3 requires a written privacy and information security program to protect non-public personal information (NPI) as required by GLBA / FTC Safeguards.

## Intake
1. Agency name, state, number of users, closings per month, underwriters.
2. Production/escrow software (e.g., SoftPro, RamQuest, Qualia, ResWare), cloud or on-prem; email platform; e-signature and portal tools.
3. Current wire controls: verbal call-back procedure, dual approval, positive-pay, wire-instruction verification service, bank alerts.
4. Existing: MFA, EDR, encryption, backups, vendor list, training, incident response plan, cyber-insurance questionnaire answers.

## Produce
1. **Written information security program summary** mapped to Pillar 3 assessment procedures: physical security of NPI; network security (firewall, patching, EDR, segmentation); disposal; access controls and least privilege; MFA for email and production systems; encryption in transit and at rest; vendor management; secure email/portal for NPI; employee training and background checks; incident response and breach notification; annual review by a qualified person.
2. **Wire fraud control checklist** (the underwriters' first question): independently verified wire instructions, no changes accepted by email, call-back to a known number, dual authorization over a threshold, bank positive pay and ACH blocks, closing-protection letters, consumer wire-fraud warnings at engagement and before closing, email domain protections (SPF, DKIM, DMARC at p=reject), lookalike-domain monitoring.
3. **Gap table**: Control | Required by Pillar 3 / Underwriter / Both | Status | Evidence | Owner | Target date.
4. **Evidence package list** for the assessor: policies, training log, vendor register, MFA screenshots, backup test record, incident log, annual review memo.

## Output format
Markdown with the four sections above; tables for the checklist and gap list; a 30/60/90-day remediation order with wire controls first.

## Guardrails
Draft for review; the agency's underwriter requirements control where they differ. Do not state the agency "meets ALTA Best Practices" — only the assessor can. If NJ: reference the NJ Department of Banking and Insurance title licensing and the NJ breach-notification statute (N.J.S.A. 56:8-163).
